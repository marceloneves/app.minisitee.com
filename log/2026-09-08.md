# 2026-09-08

## Resumo

O minisite passa a ser um arquivo HTML entregue direto pelo servidor web, sem
passar pelo app nem pelo banco. O domínio dos perfis se separa do domínio do
painel. A produção caiu uma vez (HTML apontando para arquivos de um build
antigo), o que levou à regeração automática do HTML quando o app sobe.
Versão 1.2.

### Minisite como HTML — `bb54cab`, `d92b2ee`

- Toda mudança grava o minisite em `minisites/<username>/index.html`, e o
  servidor web entrega o arquivo.
- Gravação atômica; se falhar, o app volta a montar a página.
- `scripts/publicar-html.mjs` gera todos de uma vez.

### Busca e compartilhamento — `6676eac`

### Regeração do HTML ao subir o app — `d031e69`, `629722c`

- Cada build apaga os arquivos antigos de `/_next`, e o HTML gravado continuava
  apontando para eles: foi o que derrubou a produção neste dia.
- O app regera o HTML ao subir, com trava contra rodadas simultâneas e saída em
  `publicar-html.log`.
